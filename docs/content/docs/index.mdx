# Introduction

Welcome to the vinext documentation site — a full-stack Vite-powered framework for building apps that run on Cloudflare Workers.

## What is vinext?

**vinext** is a Vite plugin that reimplements the Next.js API surface, letting you write Next.js-style Apps (App Router, `next/link`, `next/image`, etc.) and deploy them to **Cloudflare Workers** via the Cloudflare Vite plugin.

## About This Site

This documentation site itself runs on vinext, powered by:

- **Vite** instead of Next.js CLI
- **fumadocs** for the docs UI (sidebar, TOC, dark mode, search)
- **fumadocs-mdx** for Vite-based MDX compilation
- **Cloudflare Workers** for deployment
