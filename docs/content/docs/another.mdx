# Another Page

This page demonstrates using React components inside MDX, including interactive client components with state.

## Code Example

```js
let a = 1;

console.log(a);
```

## Inline Components

You can define React components directly inside MDX files and render them inline.

## External Components

Components can also be imported from separate files and used in MDX. This allows you to build rich interactive documentation.
